# اجتماع يوسف الصديق للشباب — كنيسة السيدة العذراء مريم بالقناطر الخيرية ✝️

## منظومة تسجيل الحضور والغياب الذكية بالـ QR Code (الصفحة الرئيسية)
- **157 كارت وبطاقة هوية رقمية للشباب** مع كود QR فريد لكل مخدوم.
- تصنيف المراحل الجامعية المصرية بدقة: (أولى كلية، تانية كلية، تالتة كلية، رابعة كلية، خريج).
- بيانات كاملة: الاسم، الهاتف، العنوان بالتفصيل، تاريخ الميلاد، أب الاعتراف، والمجموعة.
- تسجيل حضور فوري بكاميرا الموبايل أو مسدس الباركود.
- متابعة الغياب والافتقاد وإرسال رسائل واتساب بضغطة زر.
- تصدير كشوف الحضور والغياب إلى ملفات Excel.
- تعمل 100% بدون إنترنت (Offline Ready) عبر التخزين المحلي في المتصفح.

---

## روابط الموقع:
- **نظام الحضور والغياب وكروت الشباب (الرئيسية)**: افتح مباشرة `index.html`
- **العرض التفاعلي لخطة الخدمة السنوية (2026 - 2027)**: افتح `presentation.html` (أو اضغط زر "خطة السنة" بأعلى الشاشة)

---

## التشغيل المحلي مع السيرفر:

cd attendance
