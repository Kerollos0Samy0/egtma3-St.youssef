# اجتماع يوسف الصديق للشباب — كنيسة السيدة العذراء مريم بالقناطر الخيرية ✝️

## منظومة تسجيل الحضور والغياب الذكية بالـ QR Code (Egtma3 Youssef ElSedek)
- **157 كارت وبطاقة هوية رقمية للشباب** مع كود QR فريد لكل مخدوم.
- تصنيف المراحل الجامعية بدقة: (أولى كلية، تانية كلية، تالتة كلية، رابعة كلية، خامسة كلية).
- بيانات كاملة: الاسم، الهاتف، العنوان بالتفصيل، تاريخ الميلاد، أب الاعتراف، والمجموعة.
- تسجيل حضور فوري بكاميرا الموبايل أو مسدس الباركود.
- متابعة الغياب والافتقاد وإرسال رسائل واتساب بضغطة زر.
- مزامنة سحابية لحظية عبر Firebase Firestore وتخزين محلي يعمل بدون إنترنت (Offline Ready).
- تصدير كشوف الحضور والغياب إلى ملفات Excel.

---

## التشغيل:
- فتح `index.html` مباشرة في أي متصفح.
- أو التشغيل مع السيرفر المحلي:
```bash
cd attendance
npm install
node server.js
```
ثم فتح: `http://localhost:4000`
