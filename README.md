# اجتماع يوسف الصديق للشباب — كنيسة السيدة العذراء مريم بالقناطر الخيرية ✝️

مشروع متكامل يضم:
1. **العرض التفاعلي لخطة الخدمة السنوية (2026 - 2027)**: عروض تقديمية تفاعلية، ومؤشرات أداء، وجداول مواعيد، وأهداف الخدمة.
2. **منظومة تسجيل الحضور والغياب الذكية بالـ QR Code**:
   - قاعدة بيانات كاملة لـ **157 مخدوم** بكافة بياناتهم (الاسم، الهاتف، العنوان، تاريخ الميلاد، السنة والمرحلة الجامعية، أب الاعتراف، المجموعة).
   - بطاقات تعريفية رقمية (ID Badges) مزودة بكود QR فريد لكل مخدوم.
   - ماسح ضوئي سريع بالكاميرا للـ QR أو مسدس الباركود.
   - تسجيل الحضور والغياب وحفظ السجلات محلياً (Offline) وعلى السيرفر.
   - تصدير تقارير الحضور إلى Excel.

---

## روابط النظام السريع

- **عرض خطة السنة السنوية**: افتح `index.html`
- **نظام الحضور والغياب**: افتح `attendance/index.html`

---

## التشغيل المحلي (مع سيرفر المزامنة)

لتشغيل السيرفر المحلي لمزامنة البيانات بين خادمي الاجتماع على نفس شبكة الواي فاي:

```bash
cd attendance
npm install
node server.js
```

ثم الدخول من المتصفح على:
- `http://localhost:4000`

---

## النشر على Vercel
تم إعداد المشروع ليعمل فورياً وبشكل تلقائي بمجرد الربط مع Vercel.
- الصفحة الرئيسية: تعرض الخطة السنوية مباشرة.
- مسار `/attendance`: يفتح نظام الحضور والغياب مباشرة.
